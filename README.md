# Football match predict
Веб-приложение для расчета вероятности исхода футбольного матча на основе статистических данных

## Возможности:

- Выбор домашней и гостевой команд
- Выбор количества последних матчей для анализа исхода
- Расчет вероятности общего исхода матча (победа хозяев / ничья / победа гостей)
- Расчет вероятности точного счета в матче

## Технологии
**Backend:** Java 22, Spring Boot 3, PostgreSQL, JPA, Hibernate  
**Frontend:** JavaScript, HTML, CSS
